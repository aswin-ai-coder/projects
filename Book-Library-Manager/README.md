# Book Library Manager

A modern, private, local-first personal book catalog and reading tracker built as a static web app for GitHub Pages.

## Included
- Personal library catalog with title, author, ISBN, publisher, edition, language, series, genre, tags and shelf/location metadata
- Statuses for Want to Read, Currently Reading, Read, Did Not Finish and Wishlist
- Physical, e-book and audiobook formats
- Page counts and reading progress
- Half-star ratings, favorites, priorities, notes and reviews
- Cover image URLs
- Reading session logging with pages and minutes
- Reading journal / diary
- Lending tracker with borrower and due date
- Custom lists
- Search, status filtering and sorting
- Dashboard and library health metrics
- Genre and reading activity statistics
- Smart book picker with explainable reasons
- Library audit for missing metadata and loan issues
- Reading goals for books, pages or minutes
- JSON backup/restore
- CSV export/import
- Dark/light theme
- Responsive mobile/desktop UI
- PWA and offline caching
- No account, server, tracking or API key required

## Privacy
All library data is stored in the browser's local storage. Export a JSON backup before clearing browser storage or changing devices.

## Research basis
Feature planning was informed by current personal-library and reading-tracker patterns including cataloging, custom collections, advanced search/filtering, reading progress, ratings/reviews, lending, statistics, goals, journals and import/export. LibraryThing documents cataloging, collections, tags, ratings, reviews and imports/exports; Bookly documents reading sessions, goals, journals, loans and statistics; Goodreads' 2026 DNF release validates DNF as a useful first-class reading state.

## GitHub Pages
The project is designed to run from its folder under the repository's GitHub Pages site.
