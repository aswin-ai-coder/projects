# Reading Tracker research scope

Modern reading trackers commonly combine library status management with progress history, DNF, owned books, custom tags/lists, reading journals, challenges, queues, ratings, statistics, and data portability. Open-source/self-hosted projects add manual/ISBN metadata, author organization, cover management, session analytics and privacy-first storage. The Power Studio layer implements the useful local capabilities while keeping this GitHub Pages build dependency-free and honest about the lack of server sync or remote catalog APIs.
