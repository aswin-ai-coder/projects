# Reading Tracker — advanced scope

This build adds a local Reading Intelligence layer on top of the core tracker: deliberate Up Next queue, per-book format/series/ISBN metadata, private ratings and reviews, quotes/annotations, reading plans, year comparison, library/session analytics, daily page/minute preferences, JSON portability, encrypted AES-GCM export and local restore support.

Research basis: modern trackers emphasize custom tags/lists, DNF and owned states, reading journals, challenges, progress history and robust stats; open-source trackers add import/export, ISBN/manual metadata, author/library organization, cover management and privacy-first storage. This project keeps those ideas local-first for static GitHub Pages.
