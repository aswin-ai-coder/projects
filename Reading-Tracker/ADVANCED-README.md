# Advanced Reading Tracker Research

The Power Studio upgrade is informed by current reading products and open-source trackers. Modern patterns include custom tags/lists, built-in DNF and owned states, reading journals, progress history, reading challenges, queueing the next reads, detailed statistics, metadata/ISBN support, quotes and annotations, imports/exports, and privacy-first/self-hosted data ownership. The static build implements the useful local capabilities without pretending to provide server-backed sync or online catalog services.

Sources researched: StoryGraph, Goodreads, Bookly, Bookmory, JELU, Booktracker, LibrisLog, BookLogr, Varbook and current open-source reading tracker projects.
