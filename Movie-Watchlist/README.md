# Movie Watchlist

A modern, private, local-first movie tracker for watchlists, watched history, diary entries, ratings, reviews, tags, curated lists and personal viewing analytics.

## Features

- Watchlist, watched and DNF states
- Dated movie diary and rewatch tracking
- Five-star ratings, favorites and reviews
- Director, year, runtime, genres, tags and notes
- Search, filters and sorting
- Private curated lists
- Random watchlist picker
- Annual viewing goal
- Genre and viewing statistics
- Movie Studio with reflections and preferences
- Local restore points and JSON backup/import
- Local-first browser storage
- PWA/offline support
- Responsive light/dark/system interface
- No account, backend or telemetry

## Research basis

The interaction model was informed by current movie-tracking patterns: Letterboxd's watchlist, diary, ratings, reviews, tags, rewatches, lists, imports and statistics; broader 2026 tracker comparisons also emphasize movie/TV tracking, discovery, watch history and availability-oriented workflows. This project deliberately stays static and local-first, so it does not pretend to provide live catalog or streaming availability data without an external service.

## Platform boundary

Movie metadata is entered manually. A future hosted/API version could add live catalogs, posters, cast/crew lookup and streaming availability, but this GitHub Pages version avoids third-party API keys and remote tracking.
