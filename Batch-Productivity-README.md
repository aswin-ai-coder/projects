# Personal Productivity Batch

This batch contains 48 local-first personal productivity tools under separate folders. The apps share a small, dependency-free browser engine so they stay fast, portable and easy to maintain.

## Design principles
- Local-first: records are stored in browser `localStorage` per app.
- No accounts, backend, analytics or external service dependencies.
- Responsive semantic HTML and keyboard/touch-friendly controls.
- JSON export/import for portability.
- Search, edit, completion and delete behavior where applicable.
- Specialized views for calendars, Kanban, timers, dashboards and the suite launcher.

The implementation follows current PWA/local-first guidance around responsive layouts, offline-friendly operation and progressive enhancement. For larger future datasets, IndexedDB is the natural upgrade path.
